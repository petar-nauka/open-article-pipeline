# Evidence and review modes

Select the lightest mode that can support the requested article. These are decision guides, not source quotas.

| Mode | Typical use | Research and review |
| --- | --- | --- |
| FAST | Stable background, low-risk source-only adaptation, or editing a verified draft | Check every material new or retained claim against supplied or inspected sources; one deliberate self-review can suffice. |
| STANDARD | Default for a newly researched article | Prefer original and authoritative sources for central claims; check all high-impact claims and central interpretations; seek a separate reviewer when available. |
| STRICT | Legal, medical, safety, substantial financial or reputational claims, official-position drafts, contentious or rapidly changing status, or an explicit every-claim audit | Decompose and verify every meaningful claim; obtain current authoritative sources and contrary evidence; a truly independent second pass is needed before claiming full readiness. |

Raise the mode if evidence reveals greater risk, disputed facts, a recommendation with material consequences, or a headline resting on one weak source. Do not lower it merely to finish quickly.

Source-only, researched, and opinion are separate from these depth modes. A strict source-only rewrite can be internally faithful to the provided source while external truth remains unverified; say so plainly.

Stop collecting sources when a new source no longer changes the claim's permitted wording, important limitations, currency, independence, or editorial conclusion. For a current status, do not stop before checking for a later event.

# Source roles by claim

The best source depends on what is being asserted. Use these routes as examples, not an exhaustive hierarchy.

| Claim | Start with | Additional check |
| --- | --- | --- |
| Law, rule, deadline, official guidance | Current official text and amendment history | Jurisdiction, effective date, exceptions, later changes, interpretation versus binding text |
| Scientific result | Original paper, dataset, methods, or systematic review | Study design, sample, uncertainty, limits, replication, publication status |
| Project, product, company or policy status | Official project or institution record, filing, registry | Latest event; distinguish promise, permit, pilot, operation and measured results |
| Quantity or trend | Original dataset or statistical release | Units, denominator, time window, revisions, definition changes |
| Quote or interview | Recording, transcript, written response or firsthand statement | Exact words, speaker, date, context, translation |
| Historical event | Primary archive or reputable scholarship | Date conventions, competing accounts, later corrections |
| Practical recommendation | Relevant professional evidence or authoritative guidance | Applicability, risks, counterevidence, local context |

For a source-only task, stay within the supplied corpus for article facts. Label a source's assertion as an assertion when the corpus does not substantiate it. If the user also requests independent truth checking, handle that as a distinct verification scope.

For a fast-changing claim, distinguish three dates: when the source was released, when the described state applied, and when you checked for a later development. A recent webpage that describes an old state does not itself make the state current.

Do not confuse authority with independence. A primary source is strongest about its own decision, design, or statement; an independent source may be needed for effectiveness, impact, or contested interpretation.
